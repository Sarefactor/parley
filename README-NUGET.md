# Parley.NET

[![Website](https://img.shields.io/badge/Website-parleymaf.dev-orange)](https://parley-maf.dev)
[![License](https://img.shields.io/badge/License-MIT-orange)](LICENSE)

Parley is a .Net library built ontop of the Microsoft Agent Framework that enables the creation of workflows with a drag-and-drop editor.

It is designed to be extensible so developers can easily add specific fuctionality for their usecases to the workflows that they build.

At the time of writing (Sept 10th 2026) Parley is in a very early stage so lots of things are sort of half working and others are half baked but the general idea and foundations are in a place where I am happy for people to start using the project and seeing how far they get with it.

For more information please read the [documentation](https://parley-maf.dev/).
